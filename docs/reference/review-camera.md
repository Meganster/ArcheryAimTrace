# Масштаб траектории в Review

В Review появились три кнопки:

- **Auto** — масштаб по уже воспроизведённой части записи, с плавным отдалением во время проигрывания. При перемотке масштаб сразу соответствует выбранному моменту.
- **Aim** — масштаб по окну прицеливания от начала опорного окна до детектора; воспроизведение останавливается у детектора. Play из этого режима включает Auto.
- **Full trace** — вся проецируемая часть записи на одном масштабе.

Колесо мыши или pinch включают ручной масштаб, перетаскивание перемещает изображение. Auto сбрасывает ручное перемещение. Мишень и траектория всегда масштабируются вместе. Старые Physical / Normalized / Auto fit доступны через меню View: выбор отключает экспериментальную камеру для текущего просмотра.

Проекция при направлении более 80° от опорного луча или без пересечения плоскости мишени вперёд не рисуется экспериментальной камерой и не влияет на её масштаб. Это ограничение только визуализации: в интерфейсе появляется предупреждение, углы остаются доступны через Angles. Full trace поэтому означает всю проецируемую в этом диапазоне часть, а не любые положения лука. Сырые данные, анализ, оценка и прошивка не меняются.

## Проверка

- Проверки масштаба по префиксу записи, сингулярной проекции, пропорций, перемещения, перемотки и изменения размеров — `test/review-camera.test.js`.
- Браузерный сценарий `scripts/check-review-camera.mjs` принимает путь к экспорту через `SHOT_FILE`. Он проверяет неизменность записи, ручной zoom/pan, Auto, проигрывание и мобильную ширину. Используйте локальный экспорт, не добавляя личную запись в репозиторий.
